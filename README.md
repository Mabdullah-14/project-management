
A full-stack task management app with a drag-and-drop Kanban board and real-time updates.

## Features
- User login/signup (JWT authentication)
- Drag-and-drop task board (columns & cards)
- Real-time updates using Socket.IO
- Password reset via email

- 

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS<img width="953" height="440" alt="Screenshot 2026-09-25 012846" src="https://github.com/user-attachments/assets/cca128c4-212f-4704-9d26-200be514096f" />

- **Backend:** Node.js, Express, Prisma, PostgreSQL
- **Other:** Socket.IO, Redis, JWT

## How to Run

script : npm run dev
